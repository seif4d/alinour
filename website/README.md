# موقع د. علي نور

تعليمات التشغيل والرفع والنشر في [README الرئيسي](../README.md).

من هذا المجلد: `npm run build` ثم `npm test` ثم `npm run dev`. يتطلب Node.js 22 أو أحدث، ولا يحتاج إلى npm install.

المحتوى في `src/`، والوسائط في `assets/`، والناتج في `dist/`. تُنشر الملفات الناتجة فقط بواسطة GitHub Pages.
