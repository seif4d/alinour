# Dr. Ali Nour — Science in Motion

موقع عربي متجاوب للتعريف بالدكتور والمركز والكورسات، مبني بـ HTML وCSS وJavaScript. يضم 17 صفحة وصورًا وخطوطًا محلية، ولا يحتاج إلى قاعدة بيانات أو تثبيت مكتبات.

## التشغيل محليًا

يتطلب البناء Node.js 22 أو أحدث. من جذر المشروع:

```sh
npm --prefix website run build
npm --prefix website test
npm --prefix website run dev
```

افتح [المعاينة المحلية](http://127.0.0.1:4173). أوقف الخادم باستخدام Ctrl+C.

يمكن أيضًا فتح `website/dist/index.html` مباشرة بعد البناء.

## الرفع على GitHub

أنشئ مستودعًا فارغًا، ثم نفّذ من جذر المشروع، مع استبدال `YOUR_USERNAME` و`YOUR_REPOSITORY` بالقيم الخاصة بك:

```sh
git add .
git commit -m "Prepare Dr. Ali Nour website"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

إذا استخدمت ملف ZIP المجهز، فك الضغط أولًا ثم نفّذ `git init -b main` قبل الأوامر السابقة.

## النشر على GitHub Pages

بعد رفع الملفات، افتح إعدادات المستودع: **Settings → Pages → Build and deployment → Source → GitHub Actions**.

من تبويب **Actions**، اختر **Build and deploy website** ثم **Run workflow** على فرع `main`. بعد نجاح النشر، يظهر رابط الموقع في صفحة تشغيل المهمة وفي إعدادات Pages. تتولى المهمة البناء والفحص قبل النشر، وتنشر محتويات `website/dist` فقط. التحديثات اللاحقة على `main` تُنشر تلقائيًا؛ طلبات الدمج تُبنى وتُفحص دون نشر.

الروابط والوسائط نسبية، لذا تدعم النشر تحت اسم المستودع دون تغيير مسارات الموقع. لم يُضبط دومين مخصص أو CNAME.

## الملفات

- `website/src/`: القوالب والبيانات والتنسيق والتفاعلات.
- `website/assets/`: الصور والخطوط المحلية وترخيص خط Cairo.
- `website/build.mjs`: بناء الموقع من الملفات الموجودة داخل المشروع نفسه.
- `website/checks.mjs`: فحص الصفحات والروابط والوسائط والبيانات.
- `.github/workflows/pages.yml`: البناء والفحص والنشر.

ملفات المعاينة، الصور الأصلية الكبيرة، حزمة البحث الداخلية وملفات ZIP مستبعدة من Git. مجلد `dist` يُنشأ وقت البناء ولا يحتاج إلى الرفع.

## التواصل والمحتوى

روابط الهاتف وواتساب تفتح وسائل التواصل الخاصة بالزائر. نموذج التواصل يجهز رسالة في تطبيق البريد؛ لا يرسلها أو يخزن البيانات على خادم. أسعار البرامج ومواعيدها والشهادات معروضة وفق البيانات المقدمة، مع توضيح ضرورة تأكيدها عند التسجيل.

الصور والمحتوى خاصان بالمشروع؛ لا يمنح هذا المستودع ترخيصًا عامًا لإعادة استخدامهما. ترخيص خط Cairo موجود في `website/assets/OFL.txt`.

## معاينة روابط المشاركة

بيانات الدومين وصورة المشاركة الافتراضية في `website/src/site-config.json`. يضيف البناء روابط canonical وOpen Graph وTwitter Card لكل صفحة، مع صورة الدكتور للصفحات العامة وصورة البرنامج لصفحات الكورسات. الصور روابط HTTPS كاملة ويمكن قراءتها دون تشغيل JavaScript. عند تغيير الدومين، حدّث `url` ثم أعد البناء والنشر.
